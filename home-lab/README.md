# Virtual Home Lab — Security Monitoring & Incident Response

## Objective

Use a small virtualized Linux environment to practice security monitoring, log analysis, structured troubleshooting, and SOC-style incident documentation.

## Environment

- VirtualBox and/or VMware
- Virtualized Linux systems
- Linux authentication and system logs
- Controlled, simulated events

## Documented Investigation

| Investigation | Evidence demonstrated |
|---|---|
| [Authentication Failure Investigation](home-lab-auth-failure-investigation.md) | Repeated login failures, source and user context, successful-login checks, findings, monitoring recommendations, and closure |

## Workflow

1. Generate or identify a controlled event.
2. Review relevant logs.
3. Establish the affected user, source, and timeline.
4. Check for follow-on activity.
5. Document findings and response recommendations.
6. Close the investigation with a clear status.

## Outcome

Strengthened practical understanding of Linux authentication monitoring, alert investigation, and incident documentation in a controlled environment.

> This home lab contains no production data, real customer information, protected health information, employer records, or military operational details.
