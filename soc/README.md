# Security Operations Labs

Documented, SOC-style investigations performed with simulated events and sanitized lab data.

## Investigation Index

| Investigation | Focus |
|---|---|
| [Multiple Failed Login Attempts](soc-alert-investigation-auth-failure.md) | Authentication logs, event frequency, user/source context, successful-login checks, findings, and closure |
| [Suspicious Process Activity](soc-alert-investigation-suspicious-process.md) | Process name, execution path, parent process, user context, related events, findings, and monitoring recommendations |

## Investigation Method

1. Review the alert summary and severity.
2. Identify affected systems, users, processes, and timestamps.
3. Gather relevant logs and context.
4. Compare the activity with expected behavior.
5. Document findings without overstating certainty.
6. Recommend proportionate response actions.
7. Close or escalate based on the available evidence.

## Skills Demonstrated

- Alert triage
- Authentication-event analysis
- Process-context analysis
- Log review
- Incident documentation
- Findings and recommendations
- Escalation judgment
- Security-minded communication

> All events are simulated or lab-based. No production, employer, military, customer, or patient data is included.
