# Linux Basics — Essential Commands

## Objective

Practice foundational Linux commands used in system administration, troubleshooting, and daily technical support.

## Environment

- Red Hat–based Linux distribution
- Terminal / command line
- Controlled virtual lab

## Commands Practiced

| Command | Purpose |
|---|---|
| `pwd` | Display the current working directory |
| `ls` | List files and directories |
| `cd` | Change directories |
| `mkdir` / `rmdir` | Create or remove directories |
| `touch` | Create an empty file or update timestamps |
| `cp` | Copy files or directories |
| `mv` | Move or rename files and directories |
| `rm` | Remove files or directories |
| `cat` / `less` | View file content |
| `man` | Review command documentation |

## Activities Completed

- Navigated the Linux filesystem from the command line
- Created, copied, moved, renamed, and removed files and directories
- Viewed file content using multiple tools
- Used manual pages to review command syntax and options
- Practiced confirming the current location before making file changes

## Operational Relevance

These commands form the foundation for:

- IT support and system administration
- Linux troubleshooting
- Log and configuration review
- Automation and scripting
- Security investigations performed from the command line

## Outcome

Built a repeatable foundation for navigating and managing Linux systems safely and accurately.

## Scope

This exercise was completed in a controlled lab environment and does not represent work on a production system.
