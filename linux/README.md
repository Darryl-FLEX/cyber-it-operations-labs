# Linux Administration Labs

Hands-on Linux labs focused on practical system administration, troubleshooting, access control, service management, and log analysis in Red Hat–based environments.

## Lab Index

| Lab | Main topics |
|---|---|
| [Linux Basics — Essential Commands](linux-basics-commands.md) | Filesystem navigation, file operations, content viewing, and manual pages |
| [Users, Groups, and Permissions](linux-users-permissions.md) | Account management, group membership, ownership, `chmod`, `chown`, and least privilege |
| [Services and systemctl](linux-services-systemctl.md) | Service status, lifecycle management, startup configuration, and failure troubleshooting |
| [Logs and Troubleshooting](linux-logs-troubleshooting.md) | `journalctl`, `/var/log`, filtering, authentication events, and real-time monitoring |

## Skills Demonstrated

- Linux command-line navigation
- User and group administration
- File ownership and permissions
- Least-privilege access concepts
- `systemd` and service operations
- Linux log review and troubleshooting
- Authentication-event analysis
- Technical documentation

## Environment

- Red Hat–based Linux distributions
- Terminal / command line
- `systemd` and `journald`
- Virtualized lab systems

> These exercises are performed in controlled lab environments and are documented as labs—not production administration claims.
